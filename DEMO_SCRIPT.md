# 2-5 Minute Demo Script

## 0:00 - 0:30 Intro

- "This is Team Task Manager, a full-stack app with role-based access."
- "Tech stack: React frontend, Express/MongoDB backend, JWT auth, deployed on Railway."

## 0:30 - 1:20 Authentication

- Open app and show signup.
- Create a new user and log in.
- Log out and log back in to show login flow.

## 1:20 - 2:20 Project + Team Management

- Create a project as admin.
- Show that creator is admin automatically.
- Add a member by email to the project.
- Mention: Admin can add/remove members through project APIs.

## 2:20 - 3:30 Task Flow

- As admin, create task with title, due date, priority, assignee.
- Show task appears in task list.
- Update task status (`todo` -> `in-progress` -> `done`).

## 3:30 - 4:30 Member Role + Dashboard

- Login as member account.
- Show member only sees assigned tasks.
- Try admin-only operation (task creation) and show restriction message.
- Show dashboard metrics: total, by status, overdue.

## 4:30 - 5:00 Deployment + Repo

- Show Railway live URL.
- Show GitHub repository structure.
- Show README with setup + deployment steps.

## Closing Line

- "This project satisfies authentication, project/task management, dashboard analytics, RBAC, validations, and Railway deployment requirements."
